# タイムボックス

混み合ったタスクを15分単位の枠に放り込んで整理するための、軽量なタイムボクシングツールです。
PCとスマホの両方で使えて、データはSupabaseで同期されます。

## 使い方

| 操作             | PC                                       | スマホ                                                |
| ---------------- | ---------------------------------------- | ----------------------------------------------------- |
| 予定を入れる     | 空き枠をドラッグ（クリックだけなら15分） | 空き枠をタップ（15分）／**長押し→スライド**で範囲選択 |
| 予定を直す・消す | 予定をクリック                           | 予定をタップ                                          |
| 予定を移動       | 予定をドラッグ（週表示なら別の日へも）   | 予定を**長押し→ドラッグ**                             |
| 長さを変える     | 予定の下端をドラッグ                     | 予定を開いて終了時刻を変更                            |
| 日／週の切替     | 右上の「日・週」                         | 同左                                                  |
| 前後へ移動       | ‹ › ボタン                               | 同左                                                  |

### キー操作（PC）

| キー               | 動作                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| `↑` `↓` / `K` `J`  | カーソルを15分ずつ上下                                                        |
| `←` `→` / `H` `L`  | 前後の日へ（週の端を越えると週も移動）                                        |
| `Space` / `Enter`  | 予定があれば開く／空きなら選択開始 → `↑` `↓` で範囲を広げ、もう一度押すと登録 |
| `Esc`              | 選択を取り消し                                                                |
| `T`                | 今日へ                                                                        |
| `D` / `W`          | 日表示／週表示                                                                |
| 入力画面で `Enter` | 保存                                                                          |
| `I`                | inbox の入力欄へ（`Esc` で戻る）                                              |

メニュー（☰）→「キー操作」でも確認できます。

### inbox（まだ時間を決めていないメモ）

割り込みで来たことを、整理せずにとりあえず書いておく場所です。整理するタイミングで時間割に置きます。

| 操作 | PC | スマホ |
|---|---|---|
| 開く | 右側に常に表示（ヘッダーのトレイのボタンで開閉） | ヘッダーのトレイのボタンで下から開く |
| 書く | 入力欄に書いて Enter（`I` キーで入力欄へ） | 同左 |
| カテゴリを付ける・直す・消す | 項目をクリック（カテゴリは任意） | 項目をタップ |
| 時間割に置く | 項目を時間割へドラッグ／項目を開いて「時間割に置く」→ 枠をクリックか `Space` | 項目を開いて「時間割に置く」→ 枠をタップ |
| inbox へ戻す | 予定を開いて「inboxへ戻す」（カテゴリも引き継ぐ） | 同左 |

- 置くときは30分で入力画面が開きます（次の予定が近ければその手前まで）。時間はそこで調整できます
- 予定として保存すると inbox から消えます
- 完了・期限・並べ替えなどはあえて作っていません（inbox を第二のタスク管理にしないため）
- inbox は CSV 出力には含まれません

### ふりかえり（やってどうだったか）

あとから過去をたどれるように、感情を中心に軽く残しておく場所です。どれも任意で、空欄が普通です。

| 機能 | 書き方 |
|---|---|
| 予定のひとこと | 登録済みの予定を開くと「ふりかえり」欄がある。気分スタンプ（😆🙂😐😟😣、もう一度押すと外れる）と100文字までの文章 |
| 日記（BEAT） | 日表示で日付の見出しの「日記」ボタン（書いてあるとスタンプか ✓ が付く）。週表示では日記のある日の見出しに青い点 |
| 振り返り画面 | メニュー（☰）→「振り返り」。期間（既定は直近2週間）とキーワードで絞り込み、日ごとに日記とひとこと付きの予定が新しい順に並ぶ |
| CSV | 予定のCSVに「気分」「ひとこと」列。CSV出力で「日記」を選ぶと日記だけのCSV |

日記は BEAT 法の4項目で書きます。どの欄も任意です。

| 項目 | 中身 |
|---|---|
| B 体の感覚 | 5段階スタンプ（💪🙂😐😪🤒）＋メモ（200文字まで） |
| E 感情 | 5段階スタンプ（😆🙂😐😟😣）＋メモ（200文字まで） |
| A 行動 | 書かない。その日の予定（気分・ひとこと付き）が自動で並ぶ |
| T 思考 | 自由なメモ（1000文字まで）。以前の「日のメモ」はここに入っています |

- 時間割では、ひとことのある予定の右上に気分（文章だけなら 💬）が出ます
- 新しく予定を入れるときの入力画面には出ません（入力を軽く保つため）

- 予定の重なりは禁止です。ドラッグは既存の予定の手前で止まります
- 週表示で日付の見出しをクリックすると、その日の日表示に切り替わります
- メニュー（☰）から CSV出力・カテゴリ管理・表示設定（時間帯・週の始まり）を開けます
- 表示設定は端末ごとに保存されます（PCは8〜22時、スマホは9〜18時、のような使い分けが可能）
- 別の端末で入れた予定は、アプリの画面に戻ったときに読み直して反映されます

## セットアップ

### 1. Supabase（データの置き場所）

1. https://supabase.com でアカウントを作り、New project を作成（無料プランで十分です）
2. 左メニュー **SQL Editor** で [schema.sql](schema.sql) の中身を貼り付けて Run
3. [config.js](config.js) に記入
   - URL：`https://<プロジェクトID>.supabase.co`（プロジェクトIDはダッシュボードのURL `.../project/<ここ>/...`）
   - キー：**Settings → API Keys** の **Publishable key**（`sb_publishable_...`）。旧形式の `anon` キーでも可
   - **Secret key（`sb_secret_...`）は絶対に入れないこと**（全データを操作できる管理者用キーです）
4. **Authentication → Sign In / Providers → Email** で
   - 自分1人で使うなら「Confirm email」をオフにすると、登録後すぐにログインできます

> Publishable（anon）キーはブラウザに公開される前提のキーです。行レベルセキュリティ（RLS）により、各ユーザーは自分のデータしか読み書きできません。

### 2. 公開（GitHub Pages の例）

1. このフォルダを GitHub リポジトリに push
2. リポジトリの **Settings → Pages** で Branch を `main` / `(root)` にして Save
3. 表示された URL を開いて「新規登録」→ 以後はログインして使用
4. 自分のアカウントを作り終えたら、Supabase の **Authentication → Sign In / Providers** で
   「Allow new users to sign up」をオフにしておくと、他人に登録されません
5. スマホでは共有メニューから「ホーム画面に追加」するとアプリのように起動できます

### ローカルで試す

`config.js` が空のままなら**デモモード**（ブラウザ内にだけ保存）で動きます。
設定済みでも、URL に `?demo` を付けると（例：`http://localhost:8123/?demo`）本番データに触れずにデモモードで試せます。

```bash
python -m http.server 8123
```

http://localhost:8123 を開きます。
※ Windows の Python では `.js` が text/plain で返り読み込めないことがあります。その場合は `.claude/launch.json` のコマンドを使ってください。

## ファイル構成

| ファイル   | 役割                                                  |
| ---------- | ----------------------------------------------------- |
| index.html | 画面                                                  |
| style.css  | 見た目（ダークモード対応）                            |
| app.js     | 画面の動き（グリッド描画、範囲選択、ダイアログ、CSV） |
| store.js   | データの読み書き（Supabase／デモ用ローカル）          |
| config.js  | Supabase の接続情報                                   |
| schema.sql | テーブル定義・重なり禁止制約・RLS                     |
| sw.js      | 開くたびに最新版を確認する（GitHub Pages の10分キャッシュ対策） |

## データ

- 予定：日付、開始・終了（15分単位のスロット番号 0〜96）、カテゴリ、内容（20文字まで）
- カテゴリ：名前、色、並び順、表示／非表示
- 重なり禁止は画面とDB（排他制約 `entries_no_overlap`）の両方でチェックしています
